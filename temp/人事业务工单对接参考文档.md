## 1. 概述

四类人事业务工单均复用统一工单主表 `biz_work_order`，通过 `orderType` 字段区分类型，并各自通过一张扩展表存储业务明细（员工/公积金等信息）。

| 工单类型 | orderType | 扩展表 | 前端路由 |
|----------|-----------|--------|----------|
| 参保登记 | `BIZ_INSURANCE` | `biz_order_insurance_detail` | `/bizorder/insuranceWorkOrder` |
| 参保转出 | `BIZ_INSURANCE_OUT` | `biz_order_insurance_out_detail` | `/bizorder/insuranceOutWorkOrder` |
| 公积金转入 | `BIZ_HOUSING_FUND_IN` | `biz_order_housing_fund_in_detail` | `/bizorder/housingFundInWorkOrder` |
| 公积金封存 | `BIZ_HOUSING_FUND_SEAL` | `biz_order_housing_fund_seal_detail` | `/bizorder/housingFundSealWorkOrder` |

> 说明：这四类工单**没有各自独立的开放接口**，统一通过**通用工单开放接口** `/bizorder/openapi/workOrder/**` 进行读写，用 `orderType` + 对应扩展明细字段区分类型。

## 2. 鉴权方式

| 项目 | 说明 |
|------|------|
| 鉴权类型 | 静态 Token（请求头校验） |
| 请求头名称 | `X-Open-Token` |
| 配置项 | 服务端 `bizorder.openapi.token`（DB 动态管理） |
| 生效范围 | 所有 `/bizorder/openapi/*` |
| Token 获取 | 由本系统运维/对接方线下分配（OpenAPI 管理页面） |

> 注意：`workOrder` 属于**业务接口**，要求 Token 必须绑定租户（`biz_open_api_token.tenant_id` 非空），否则返回 403。

**鉴权失败响应**：

```json
{ "success": false, "code": 401, "message": "无效的开放接口 Token" }
```

```json
{ "success": false, "code": 403, "message": "该 Token 未绑定租户，无法访问业务接口" }
```

## 4. 通用工单接口

**Base URL**: `{host}/jeecg-boot/bizorder/openapi/workOrder`

### 4.1 接口清单

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/list` | 分页列表（按 orderType 等条件过滤） |
| GET | `/queryById?id=` | 聚合详情（主单 + 扩展明细 + 事项明细 + 经办人） |
| POST | `/add` | 创建工单（含扩展明细，自动关联客户） |
| PUT | `/edit` | 编辑工单（含扩展明细） |
| POST | `/transit?id=&targetStatus=` | 工单状态流转 |

### 4.2 列表查询参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| pageNo | int | 否 | 页码，默认 1 |
| pageSize | int | 否 | 每页条数，默认 10 |
| orderNo | string | 否 | 工单编号 |
| orderType | string | 否 | 工单类型，如 `BIZ_INSURANCE` |
| orderStatus | string | 否 | 工单状态，如 `PENDING` |
| enterpriseName | string | 否 | 企业名称 |
| creditCode | string | 否 | 统一社会信用代码 |

### 4.3 状态流转参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | string | 是 | 工单 ID |
| targetStatus | string | 是 | 目标状态（见 7.2 状态机） |

## 5. 数据模型

### 5.1 聚合对象 WorkOrderPage

创建/编辑/详情均使用同一结构（按 `orderType` 携带对应扩展明细对象）：

```json
{
  "workOrder": { ... },
  "itemList": [ ... ],
  "agent": { ... },
  "insuranceDetail": { ... },
  "insuranceOutDetail": { ... },
  "housingFundInDetail": { ... },
  "housingFundSealDetail": { ... }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| workOrder | object | 工单主表（必传） |
| itemList | array | 事项明细列表（通用工单使用） |
| agent | object | 经办人信息（查询返回） |
| insuranceDetail | object | 参保登记扩展明细（`BIZ_INSURANCE`） |
| insuranceOutDetail | object | 参保转出扩展明细（`BIZ_INSURANCE_OUT`） |
| housingFundInDetail | object | 公积金转入扩展明细（`BIZ_HOUSING_FUND_IN`） |
| housingFundSealDetail | object | 公积金封存扩展明细（`BIZ_HOUSING_FUND_SEAL`） |

### 5.2 工单主表 workOrder

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | string | 编辑必填 | 主键，新增可不传 |
| orderNo | string | 否 | 工单编号，留空自动生成 |
| orderType | string | **是** | 四类之一：`BIZ_INSURANCE` / `BIZ_INSURANCE_OUT` / `BIZ_HOUSING_FUND_IN` / `BIZ_HOUSING_FUND_SEAL` |
| enterpriseName | string | 否 | 企业名称（不传 customerId 时用于自动查找/创建客户） |
| creditCode | string | 否 | 统一社会信用代码 |
| customerId | string | 否 | 关联客户 ID（不传且传了 enterpriseName 时自动关联） |
| agentId | string | 否 | 经办人 ID |
| wechatMappingKey | string | 否 | 微信路由唯一凭证，格式 `{robot_wxid}:{chat_type}:{target_wxid}` |

### 5.3 参保登记扩展 insuranceDetail

> 表 `biz_order_insurance_detail`，对应 `orderType = BIZ_INSURANCE`

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| employeeName | string | **是** | 员工姓名 |
| idCard | string | **是** | 证件号码 |
| employmentStartDate | date | **是** | 就业起始日期（`yyyy-MM-dd`） |
| contractSignType | string | **是** | 合同签订方式：`未签` / `初签` |
| contractTerm | string | **是** | 合同期限：`固定期限劳动合同` / `无固定期限劳动合同` / `以完成一定工作任务为期限` |
| contractStartDate | date | **是** | 合同开始日期（`yyyy-MM-dd`） |
| contractEndDate | date | **是** | 合同结束日期（`yyyy-MM-dd`） |
| employmentForm | string | 否 | 用工形式，默认 `全日制` |
| isDispatch | string | 否 | 是否劳务派遣：`是` / `否`，默认 `否` |

### 5.4 参保转出扩展 insuranceOutDetail

> 表 `biz_order_insurance_out_detail`，对应 `orderType = BIZ_INSURANCE_OUT`

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| employeeName | string | **是** | 员工姓名 |
| idCard | string | **是** | 证件号码 |

### 5.5 公积金转入扩展 housingFundInDetail

> 表 `biz_order_housing_fund_in_detail`，对应 `orderType = BIZ_HOUSING_FUND_IN`

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| employeeName | string | **是** | 员工姓名 |
| idCard | string | **是** | 证件号码 |
| fundAccount | string | **是** | 公积金账号 |
| fundBase | decimal | **是** | 公积金基数 |

### 5.6 公积金封存扩展 housingFundSealDetail

> 表 `biz_order_housing_fund_seal_detail`，对应 `orderType = BIZ_HOUSING_FUND_SEAL`

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| employeeName | string | **是** | 员工姓名 |
| idCard | string | **是** | 证件号码 |
| fundAccount | string | **是** | 公积金账号 |
| leaveDate | date | 否 | 退工日期（`yyyy-MM-dd`） |
| sealReason | string | 否 | 封存原因 |

X-Open-Token: <your-token>

    "orderType": "BIZ_INSURANCE",
    "enterpriseName": "上海星辰贸易有限公司",
    "creditCode": "91310000MA002B002X",
    "agentId": "2059454092242161666",
    "isFinalSubmit": 0
  },
  "insuranceDetail": {
    "employeeName": "张三",
    "idCard": "310101199001011234",
    "employmentStartDate": "2026-08-01",
    "contractSignType": "初签",
    "contractTerm": "固定期限劳动合同",
    "contractStartDate": "2026-08-01",
    "contractEndDate": "2029-07-31",
    "employmentForm": "全日制",

## 7. 字典与枚举

### 7.1 工单类型 biz_order_type

| item_value | item_text |
|------------|-----------|
| BIZ_INSURANCE | 参保登记工单 |
| BIZ_INSURANCE_OUT | 参保转出工单 |
| BIZ_HOUSING_FUND_IN | 公积金转入工单 |
| BIZ_HOUSING_FUND_SEAL | 公积金封存工单 |

### 7.2 工单状态 biz_order_status

| item_value | item_text |
|------------|-----------|
| PREPARING | 材料准备中 |
| CONFIRM_BY_C | 待客户确认 |
| CONFIRM_BY_A | 待经办人确认 |
| PENDING | 待提交 |
| QUEUED | 已入队（待执行） |
| DISPATCHED | 已下发 RPA |
| RUNNING | RPA 执行中 |
| WAIT_CONFIRM | RPA 执行完成待确认 |
| DONE | 已办结 |
| DRAFT | 草稿 |
| PROCESSING | 处理中 |
| CANCEL | 已取消 |

**状态机流转规则**（`/transit` 仅允许按以下方向流转）：

| 当前状态 | 可流转到 |
|----------|----------|
| PREPARING | CONFIRM_BY_C / CONFIRM_BY_A / PENDING |
| CONFIRM_BY_C | CONFIRM_BY_A |
| CONFIRM_BY_A | PENDING |
| PENDING | QUEUED / DISPATCHED / DRAFT / CANCEL |
| QUEUED | DISPATCHED / PENDING |
| DRAFT | PROCESSING / CANCEL / DRAFT |
| PROCESSING | DONE |
| DISPATCHED | RUNNING / PENDING |
| RUNNING | WAIT_CONFIRM / DONE / PENDING |
| WAIT_CONFIRM | DONE |
| DONE / CANCEL | （终态，不可再流转） |
