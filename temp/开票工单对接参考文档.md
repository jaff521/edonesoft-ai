## 1. 概述

开票工单是一种特殊的工单类型（`orderType = "BIZ_INVOICE"`），通过扩展表 `biz_order_invoice` 存储购方信息，通过 `invoice_order_detail` 表存储开票明细行。

外部系统通过 **开放接口**（静态 Token 鉴权）进行读写，接口路径前缀为 `/bizorder/openapi/invoiceWorkOrder/**`。

---

## 2. 鉴权方式

| 项目 | 说明 |
|------|------|
| 鉴权类型 | 静态 Token（请求头校验） |
| 请求头名称 | `X-Open-Token` |
| 配置项 | 服务端 `bizorder.openapi.token` |
| 生效范围 | 所有 `/bizorder/openapi/*` |
| Token 获取 | 由本系统运维/对接方线下分配 |

**鉴权失败响应**：

```json
{ "success": false, "code": 401, "message": "无效的开放接口 Token" }
```

## 4. 开票工单接口

**Base URL**: `{host}/jeecg-boot/bizorder/openapi/invoiceWorkOrder`

### 4.1 接口清单

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/list` | 分页列表（含购方/金额等扩展字段） |
| GET | `/queryById?id=` | 聚合详情（主单 + 扩展 + 明细行） |
| POST | `/add` | 创建开票工单（含明细） |
| PUT | `/edit` | 编辑开票工单 |

### 4.2 列表查询参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| pageNo | int | 否 | 页码，默认 1 |
| pageSize | int | 否 | 每页条数，默认 10 |
| orderNo | string | 否 | 工单编号 |
| enterpriseName | string | 否 | 企业名称（模糊） |
| creditCode | string | 否 | 信用代码（模糊） |
| orderStatus | string | 否 | 工单状态，如 `PENDING` |

## 5. 历史发票数据接口

**Base URL**: `{host}/jeecg-boot/bizorder/openapi/invoice`

> 注意：此接口查询的是 **RPA 抓取回来的历史发票数据**（`biz_invoice_info` / `biz_invoice_detail`），不是工单。

### 5.1 接口清单

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/list` | 发票分页列表 |
| GET | `/queryById?id=` | 单条发票 + 明细行 |
| GET | `/getByCustomerCreditCode?creditCode=` | 按客户信用代码查 |
| GET | `/getByCustomerId?customerId=` | 按客户ID查 |

### 5.2 查询参数

| 参数 | 说明 |
|------|------|
| pageNo / pageSize | 分页 |
| invoiceNo | 发票编号 |
| sellerName | 销售方名称（模糊） |
| buyerName | 购买方名称（模糊） |

## 6. 税收分类编码接口

**Base URL**: `{host}/jeecg-boot/bizorder/openapi/taxCategory`

数据来源：`biz_tax_category` 表（商品和服务税收分类编码，当前约 4122 条）。

### 6.1 接口清单

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/search?keyword=&limit=50` | 模糊搜索（匹配编码/名称/简称），仅返回叶子节点 |
| GET | `/children?parentCode=` | 查询指定编码的子节点 |
| GET | `/getByCode?code=` | 按 19 位编码精确查询 |
| GET | `/page?keyword=&pageNo=&pageSize=` | 分页查询 |

## 7. 数据模型

### 7.1 聚合对象 WorkOrderPage

创建/编辑/详情均使用同一结构：

```json
{
  "workOrder": { ... },
  "invoiceOrder": { ... },
  "invoiceDetailList": [ ... ]
}
```

### 7.2 工单主表 workOrder

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | string | 编辑必填 | 主键，新增可不传 |
| orderNo | string | 否 | 工单编号，留空自动生成（GS+日期+6位序号） |
| enterpriseName | string | **是** | 企业名称 |
| creditCode | string | 否 | 统一社会信用代码 |
| agentId | string | 否 | 经办人 ID |
| orderStatus | string | 否 | 默认 `PREPARING` |
| isFinalSubmit | int | 否 | 是否最终提交，1=是 0=否 |

### 7.3 发票扩展信息 invoiceOrder

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| buyerName | string | **是** | 购买方名称 |
| buyerCreditCode | string | 否 | 购买方统一信用代码 |
| invoiceType | string | **是** | `BLUE_INVOICE`(蓝字) / `RED_INVOICE`(红字) |
| invoiceCategory | string | **是** | `SPECIAL_VAT_INVOICE`(专票) / `NORMAL_INVOICE`(普票) |
| invoiceRemark | string | 否 | 开票备注 |

### 7.4 开票明细行 invoiceDetailList

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| itemName | string | **是** | 项目名称 |
| goodsServiceTaxCode | string | 否 | 商品和服务税收分类编码（19位） |
| spec | string | 否 | 规格型号 |
| unit | string | 否 | 单位 |
| quantity | decimal | **是** | 数量 |
| unitPrice | decimal | **是** | 单价 |
| amount | decimal | 否 | 金额（可不传，服务端自动 = 数量×单价） |
| taxRate | string | **是** | 税率，如 `13%`、`6%`、`0%` |

### 7.5 税收分类编码 BizTaxCategory

| 字段 | 类型 | 说明 |
|------|------|------|
| code | string | 合并编码（19位） |
| parentCode | string | 父级编码 |
| name | string | 货物和劳务名称 |
| shortName | string | 分类简称 |
| level | int | 层级深度 0-9 |
| isLeaf | int | 1=叶子节点（可选择用于开票） |

## 8. 完整对接示例

### 8.1 创建开票工单

```http
POST /jeecg-boot/bizorder/openapi/invoiceWorkOrder/add
X-Open-Token: <your-token>
Content-Type: application/json
```

```json
{
  "workOrder": {
    "enterpriseName": "上海星辰贸易有限公司",
    "creditCode": "91310000MA002B002X",
    "agentId": "2059454092242161666",
    "isFinalSubmit": 0
  },
  "invoiceOrder": {
    "buyerName": "北京某科技有限公司",
    "buyerCreditCode": "91110108MA01XXXXX",
    "invoiceType": "BLUE_INVOICE",
    "invoiceCategory": "SPECIAL_VAT_INVOICE",
    "invoiceRemark": "项目一期开发费"
  },
  "invoiceDetailList": [
    {
      "itemName": "软件开发服务",
      "goodsServiceTaxCode": "1090601020000000000",
      "unit": "项",
      "quantity": 1,
      "unitPrice": 100000,
      "taxRate": "6%"
    },
    {
      "itemName": "技术咨询服务",
      "unit": "次",
      "quantity": 2,
      "unitPrice": 5000,
      "taxRate": "6%"
    }
  ]
}
```

**响应**：
```json
{ "success": true, "code": 200, "result": "添加成功！id=2082323735033016330" }
```

### 8.2 查询详情

```http
GET /jeecg-boot/bizorder/openapi/invoiceWorkOrder/queryById?id=2082323735033016330
X-Open-Token: <your-token>
```

### 8.3 搜索税收编码

```http
GET /jeecg-boot/bizorder/openapi/taxCategory/search?keyword=软件&limit=10
X-Open-Token: <your-token>
```

## 9. 字典与枚举

### 9.1 工单状态 biz_order_status

| item_value | item_text |
|------------|-----------|
| PREPARING | 材料准备中 |
| CONFIRM_BY_C | 待客户确认 |
| CONFIRM_BY_A | 待经办人确认 |
| PENDING | 待提交 |
| DISPATCHED | 已下发RPA |
| RUNNING | RPA执行中 |
| WAIT_CONFIRM | RPA执行完成待确认 |
| DONE | 已办结 |

### 9.2 开票类别 invoiceType

| item_value | item_text |
|------------|-----------|
| BLUE_INVOICE | 蓝字发票 |
| RED_INVOICE | 红字发票 |

### 9.3 发票类别 invoiceCategory

| item_value | item_text |
|------------|-----------|
| SPECIAL_VAT_INVOICE | 增值税专用发票 |
| NORMAL_INVOICE | 普通发票 |

### 9.4 税率常见值

| 值 | 说明 |
|----|------|
| 13% | 一般货物/劳务 |
| 9% | 不动产/运输 |
| 6% | 现代服务业 |
| 3% | 简易征收 |
| 0% | 免税/零税率 |
