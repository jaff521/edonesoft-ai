# 经营范围变更 (SCOPE) 参考文档

## 办理逻辑
1. **收集变更前经营范围**：从企业查询结果中自动获取当前经营范围全文，无需客户手动提供。
2. **收集变更后经营范围**：请客户提供变更后的完整经营范围描述。
   - 多条经营项目之间使用顿号或分号分隔。
   - 提醒客户提供完整的经营范围文本（不只是新增/删除的部分）。
3. 不需要收集任何证件照片。

## 字段结构规范
```json
{
  "itemName": "SCOPE",
  "beforeChange": {
    "scope": "{原经营范围全文}"
  },
  "afterChange": {
    "scope": "{新经营范围全文}"
  }
}
```
