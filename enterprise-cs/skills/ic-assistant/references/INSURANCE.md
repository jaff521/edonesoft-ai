# 参保登记 (INSURANCE)

> 本文档为 ic-assistant 在处理「参保登记」人事事项时的业务参考文档。

---

## 办理逻辑

### 一、确认企业与员工基本信息

- 复用 Step 1 中已查询的企业名称和统一社会信用代码。
- 收集员工姓名与身份证号码。若客户提供了身份证照片，自动调用 `validate_document.py` 识别并提炼姓名与 18 位身份证号，向客户确认无误。

### 二、收集参保登记扩展明细

逐步收集以下参保登记所需信息：

| 字段 | 必填 | 默认与处理规则 |
|------|------|----------------|
| 员工姓名 | ✅ | 身份证姓名 |
| 身份证号 | ✅ | 18 位身份证号码 |
| 就业起始日期 | ✅ | 格式 `yyyy-MM-dd` |
| 合同签订方式 | ✅ | `未签` / `初签` |
| 合同期限 | ✅ | `固定期限劳动合同` / `无固定期限劳动合同` / `以完成一定工作任务为期限` |
| 合同开始日期 | ✅ | 格式 `yyyy-MM-dd` |
| 合同结束日期 | ✅ | 格式 `yyyy-MM-dd`（须晚于或等于开始日期） |
| 用工形式 | ❌ | 默认 `全日制` |
| 是否劳务派遣 | ❌ | 默认 `否` |

---

### 三、汇总确认与建单（强约束步骤）

将所有收集到的信息**逐字段**汇总展示给客户：

> 【参保登记工单信息汇总】
> 
> 销方企业：上海星辰贸易有限公司
> 业务类型：参保登记
> 
> 员工信息：
> - 员工姓名：张三
> - 身份证号：310101199001011234
> - 就业起始日期：2026-08-01
> - 合同签订方式：初签
> - 合同期限：固定期限劳动合同
> - 合同开始日期：2026-08-01
> - 合同结束日期：2029-07-31
> - 用工形式：全日制
> - 是否劳务派遣：否
> 
> 请核对以上信息是否正确。确认无误请回复“确认”，我将为您创建参保登记工单。

> [!IMPORTANT]
> **必须在用户明确回复“确认”后方可触发建单**：严禁自动或提前触发 `hr-creator` Skill 创建工单。

---

## 字段结构规范

客户确认后，组装以下 JSON 调用 `hr-creator` Skill：

```json
{
  "sessionKey": "{sessionKey}",
  "workOrder": {
    "enterpriseName": "{企业名称}",
    "creditCode": "{统一社会信用代码}",
    "orderType": "BIZ_INSURANCE"
  },
  "insuranceDetail": {
    "employeeName": "{员工姓名}",
    "idCard": "{身份证号}",
    "employmentStartDate": "{yyyy-MM-dd}",
    "contractSignType": "{未签 或 初签}",
    "contractTerm": "{固定期限劳动合同 等}",
    "contractStartDate": "{yyyy-MM-dd}",
    "contractEndDate": "{yyyy-MM-dd}",
    "employmentForm": "全日制",
    "isDispatch": "否"
  }
}
```
