# 经营地址变更 (ADDR) 参考文档

## 办理逻辑
1. **收集变更前地址**：从企业查询结果中自动获取当前经营地址，无需客户手动提供。
2. **收集变更后地址**：询问客户新的完整经营地址。
   - 地址应包含省/市/区/街道/门牌号/室号等完整信息。
   - 如客户提供不完整，应主动追问补全。
3. 不需要收集任何证件照片。

## 字段结构规范
```json
{
  "itemName": "ADDR",
  "beforeChange": {
    "address": "{原经营地址}"
  },
  "afterChange": {
    "address": "{新经营地址}"
  }
}
```
