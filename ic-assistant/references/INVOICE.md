# 发票开票 (INVOICE)

> 本文档为 ic-assistant 在处理「发票开票」事项时的业务参考文档。

---

## 办理逻辑

### 一、确认销方企业信息

- 复用 Step 1 中已查询的企业名称和统一社会信用代码作为销方信息
- 向客户确认是否正确

### 二、收集购方信息

逐步询问以下信息：

| 字段 | 必填 | 说明 |
|------|------|------|
| 购买方名称 | ✅ | 对方公司全称 |
| 购买方统一社会信用代码 | ✅（公司） | **当购买方名称包含“公司”、“有限”、“集团”等企业关键词时为必填。**助手**必须**自动调用 `python3 {baseDir}/scripts/unified_query.py "{购买方名称}"` 查询获取 18 位信用代码，向客户展示并请客户确认无误后，填入 `buyerCreditCode` 提交（严禁跳过此步骤） |
| 发票类型 | ✅ | 蓝字发票（正常开票）或红字发票（冲红） |
| 发票类别 | ✅ | 增值税专用发票（专票）或普通发票（普票） |
| 开票备注 | ❌ | 如项目名称、合同编号等 |

> [!IMPORTANT]
> **购方信用代码必须自动查询并经客户确认**：当购买方为企业（名称包含“公司”、“有限”、“集团”等关键词）时，助手**必须主动调用** `unified_query.py` 查询信用代码，并告知客户（例如：“已为您查到购方的统一社会信用代码为：`91310114...`，请您确认是否正确？”）。**必须在客户确认无误后，方可将其填入 `buyerCreditCode` 提交建单**。严禁跳过查询、严禁未经确认直接提交。

### 三、收集开票明细行

逐行收集，每行包含：

| 字段 | 必填 | 说明 |
|------|------|------|
| 项目名称 | ✅ | 如"软件开发服务"、"技术咨询费"等 |
| 规格型号 | ❌ | |
| 单位 | ❌ | 如"项"、"次"、"套"等 |
| 数量 | ✅ | |
| 单价 | ✅ | 单位为元 |
| 税率 | ✅ | 常见值：6%（现代服务业）、13%（一般货物）、9%（运输/不动产）、3%（简易征收）、0%（免税） |

询问客户是否还有更多明细行，直到客户确认收集完毕。

### 四、汇总确认

将所有收集到的开票信息汇总展示给客户确认，格式示例：

> 开票信息汇总：
> 销方：上海星辰贸易有限公司
> 购方：北京某科技有限公司
> 购方信用代码：91110108MA01XXXXX（请核对）
> 类型：蓝字增值税专用发票
> 明细：
>   1. 软件开发服务 × 1项 × 100000元，税率6%
>   2. 技术咨询服务 × 2次 × 5000元，税率6%
> 请确认以上信息无误。

## 字段结构规范

客户确认后，组装以下 JSON 调用 `invoice-creator` Skill：

```json
{
  "sessionKey": "{sessionKey}",
  "workOrder": {
    "enterpriseName": "{销方企业全名}",
    "creditCode": "{销方统一社会信用代码}"
  },
  "invoiceOrder": {
    "buyerName": "{购买方名称}",
    "buyerCreditCode": "{购买方信用代码}",
    "invoiceType": "{BLUE_INVOICE 或 RED_INVOICE}",
    "invoiceCategory": "{SPECIAL_VAT_INVOICE 或 NORMAL_INVOICE}",
    "invoiceRemark": "{开票备注}"
  },
  "invoiceDetailList": [
    {
      "itemName": "{项目名称}",
      "taxKeyword": "{项目名称关键词，用于自动匹配税收编码}",
      "spec": "{规格型号}",
      "unit": "{单位}",
      "quantity": "{数量}",
      "unitPrice": "{单价}",
      "taxRate": "{税率}"
    }
  ]
}
```

### 字段映射说明

| 客户表述 | 字段值 |
|----------|--------|
| 蓝字发票 / 正常开票 | `invoiceType: "BLUE_INVOICE"` |
| 红字发票 / 冲红 | `invoiceType: "RED_INVOICE"` |
| 专票 / 增值税专用发票 | `invoiceCategory: "SPECIAL_VAT_INVOICE"` |
| 普票 / 普通发票 | `invoiceCategory: "NORMAL_INVOICE"` |

### 税收编码说明

- 每个明细行的 `taxKeyword` 字段用于自动搜索匹配税收分类编码（19位）
- 脚本会调用 `/taxCategory/search` 接口自动填充 `goodsServiceTaxCode`
- 如果客户已经明确提供了编码，可直接传入 `goodsServiceTaxCode` 字段替代 `taxKeyword`

---

## 注意事项

1. 开票工单调用的 Skill 是 `invoice-creator`（不是 `ticket-creator`）
2. 开票工单创建成功后无 H5 确认页，回复模板为：
   > ✅ 开票工单已创建，工单号：`{ticket_id}`。请等待经办人确认后进行后续开票操作。
3. 如果客户同时选择了工商变更事项和发票开票，需要分别创建两个独立的工单
